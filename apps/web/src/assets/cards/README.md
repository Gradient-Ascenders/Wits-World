# Wits World celestial engraving

engraving. These original monochrome masks share radial geometry and fine
strokes. CSS supplies each rarity's material, relief and responsive visibility.
They are decorative, non-interactive, and hidden from assistive technology.

The supplied reference PNGs remain under `docs/design/references/card-frames`;
none is imported into the application.
