# Explore campus

## Player journey

1. Open **Events** and select an event from the map or list.
2. Choose **Enable live location** if prompted.
3. Check the range status. If out of range, move closer and wait for an update.
4. Choose **Start challenge** when **In range** appears.

Other Explore views provide additional ways to browse:

| View        | Action                                                        |
| ----------- | ------------------------------------------------------------- |
| Nearby      | Enable location and find unvisited events.                    |
| Trails      | Select a trail to inspect its steps and next available event. |
| Territories | Select a zone to inspect its status.                          |

## How it works

The map and event list display the same API records. Selecting an active event
checks its availability and your reported location on the server. Location
updates can refresh the range status; starting a challenge rechecks access.

Previously granted permission enables live location automatically. The watcher
pauses while Explore is hidden and stops when you leave. Map presentation does
not determine eligibility.
Browsing remains available without location.

Detailed thresholds and retention are covered by
[event eligibility](../database/event-eligibility.md) and
[movement privacy](../database/movement-evidence.md).
